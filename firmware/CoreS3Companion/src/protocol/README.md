# Protocol

`AgentStatusMessage` 实现与硬件无关的变长状态帧解析，覆盖状态、来源、额度、Context、
额度重置剩余分钟数、UTF-8 标题、模型名称、effort、未接电源/已接电源熄屏分钟数和活动
标记，并供设备固件与 native 单元测试复用。解析器继续接受不带扩展后缀、只带模型后缀，
以及使用单一熄屏字段的旧 Agent 状态帧，用于协议回归测试和开发期迁移验证。

正式运行时，固件必须与 macOS 客户端来自同一个 Release 标签。项目不提供跨版本协商，
解析器保留旧帧测试路径不构成跨 Release 兼容承诺。

`CpuMessage` 只为第一版三字节协议的兼容测试保留。
